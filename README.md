# AI Code Review Tool (SAR)

SAR is an AI-powered code review tool designed to analyze source code and generate structured review feedback automatically.  
It helps developers identify issues, improve code quality, and save time by reducing the need for manual code reviews.

This project focuses on simplicity — run it locally, analyze any code file or folder, and get a clean report instantly.

---

## 🔹 What This Project Does

- Scans your Python source code
- Analyzes logic, structure, and potential issues
- Generates a review report (PDF / text format)
- Saves outputs locally for easy access

Perfect for:
- Students & beginners learning code quality
- Solo developers
- Internal project reviews
- AI automation experiments

## ✅ Requirements

- Python 3.9 or above

Install dependencies:
```bash
pip install -r requirements.txt
````

---

## ▶️ Run the Project

Analyze any source file or directory:

```bash
python main.py --source path/to/code --output tmp_reports/
```

Example:

```bash
python main.py --source sample.py --output tmp_reports/
```

View the generated review inside:

```
tmp_reports/
```
